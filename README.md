# E-Market Analysis Dashboard

An end-to-end Power BI business intelligence project analyzing e-commerce transactions, fulfillment workflows, customer purchasing behavior, and profitability.

---

## 📌 Project Overview

This repository contains the dataset files, lab documentation, and Power BI report (`.pbix`) for the **E-Market Analysis** practical assignment. The project links order records with itemized fulfillment details to provide visibility into sales volume, profit margins, product category performance, and regional customer trends.

---

## 🗂️ Repository Structure

| File / Resource | Description |
| :--- | :--- |
| `Practical 6.pbix`[cite: 5] | Power BI Desktop report containing the relational data model, custom DAX measures, and interactive visual dashboards[cite: 5] |
| `Orders.csv`[cite: 5] | Header-level transaction records covering order dates, customer names, state, city, and shipment details[cite: 5] |
| `Details.csv`[cite: 5] | Item-level transaction lines containing order amount, profit, quantity, category, and sub-category[cite: 5] |
| `Practical 6 questions.docx`[cite: 5] | Assignment problem statements, required analytical queries, and dashboard objectives[cite: 5] |
| `Practical 6.docx`[cite: 5] | Completed practical documentation detailing data prep steps, methodology, and visual interpretation[cite: 5] |

---

## 📊 Key Highlights & Metrics

* **Sales & Profit Optimization:** Tracking total revenue, net profit, and profit margin percentages across order batches[cite: 5].
* **Category & Sub-Category Insights:** Identifying top-performing product categories (e.g., Electronics, Clothing, Furniture) and tracking quantity demand[cite: 5].
* **Customer & Regional Spread:** Analyzing order concentration across cities and states to evaluate geographical market reach[cite: 5].
* **Payment & Order Dynamics:** Evaluating transaction quantities, average order value (AOV), and customer buying frequency[cite: 5].

---

## 🛠️ Tools & Technologies Used

* **Power BI Desktop:** Star/snowflake schema design, relationship modeling between Orders and Details, and DAX calculations[cite: 5].
* **Power Query:** Data profiling, type setting, relational key validation, and data cleaning[cite: 5].
* **Data Sources:** Tabular e-commerce files (`Orders.csv` and `Details.csv`)[cite: 5].
